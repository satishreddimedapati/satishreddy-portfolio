## 📌 Project 2: EMI & Financial Management Suite (Enterprise Ledger)

### 1. Project Overview & Name
- **Project Name:** EMI & Financial Management Suite
- **Category:** Featured Live Financial Database Platform
- **Live Application Link:** [https://manafinance1.web.app/](https://manafinance1.web.app/)
- **Repository:** [GitHub Repository](https://github.com/satishreddimedapati)

### 2. Core Purpose & Problem Solved
Small business owners and private lenders often rely on error-prone paper ledgers or Excel spreadsheets to track loan schedules, EMI repayments, and daily cash transactions. This suite digitizes the complete ledger process with secure customer profiles, automated interest calculation, and transaction history.

### 3. Technology Stack
- **Frontend Framework:** Angular (Standalone architecture, Reactive Forms)
- **Backend API:** ASP.NET Core RESTful Web API
- **Database:** Microsoft SQL Server (T-SQL Stored Procedures, EF Core)
- **Hosting:** Firebase Web Hosting

### 4. Key Architectural Features
- **Customer Loan & Schedule Generator:** Automatically builds EMI payback timelines with compound/simple interest calculations.
- **Daily Transaction Log:** Strict audit logging ensuring zero data loss (`Customer ➔ Loan ➔ Transaction`).
- **Reporting Engine:** Exportable ledger summaries for daily cash flows.

### 5. Quantifiable Impact & Metrics
- **Accuracy Improvement:** Improved ledger reporting accuracy by **35%** across 200+ daily transactions.
- **Workflow Speed:** Cut manual record-keeping time from hours to under 2 minutes per entry.
